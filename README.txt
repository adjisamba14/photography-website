
README – Photography Company Website Prototype (Unit 9 Product)

What this is
- A static, front-end prototype demonstrating the user interface flows requested by the client.
- All forms and transactions are mock (no back-end processing).

How to run locally
1) Download and unzip the package.
2) Open index.html in any modern browser.
3) Navigate using the top menu; ensure the css/ and js/ folders remain in the same structure.

What to test
- Navigation across all pages (10+ pages, internal links only).
- Add-to-cart buttons increment a counter (prototype only).
- Booking and Touch-Up forms show fields and mock submission.
- Checkout → Confirmation flow shows required steps and confirmation page.

Pages included
- index.html, about.html, services.html, gallery.html, booking.html, touchup.html, cart.html, checkout.html, confirmation.html, faq.html, contact.html, privacy.html, terms.html.

Deployment (optional)
- You can drag-drop the folder into GitHub Pages or Netlify as a static site. No build step required.
